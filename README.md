# Emergency Light (แอปไฟฉุกเฉิน)

แอป Android ที่ใช้ไฟฉายและหน้าจอมือถือเป็นแสง ให้คนขับรถมองเห็นเราตอนเดินในที่มืด
พร้อมปุ่ม SOS เสียงไซเรนที่กดได้ทันทีเมื่อเปิดแอป — ทำงานแบบออฟไลน์ 100% ไม่ใช้อินเทอร์เน็ตเลย

---

## 1. อัปโหลดขึ้น GitHub (ทำครั้งแรกครั้งเดียว)

1. เข้า https://github.com แล้วล็อกอิน (ถ้ายังไม่มีบัญชี ให้สมัครฟรีก่อน)
2. กดปุ่ม **+** มุมขวาบน → **New repository**
3. ตั้งชื่อ เช่น `EmergencyLight` → เลือก **Private** หรือ **Public** ก็ได้ → กด **Create repository**
4. ในหน้าที่ขึ้นมา กดลิงก์ **uploading an existing file**
5. แตกไฟล์ `EmergencyLight-project.zip` ในคอมพิวเตอร์ก่อน แล้วเปิดโฟลเดอร์ `EmergencyLight`
6. **เลือกทุกอย่างข้างในโฟลเดอร์** (รวมโฟลเดอร์ `.github` และ `app`) แล้วลากไปวางในหน้าเว็บ
   - สำคัญ: ต้องลาก "ของข้างใน" ไม่ใช่ลากตัวโฟลเดอร์ `EmergencyLight` ทั้งก้อน
   - ถ้าในคอมพิวเตอร์มองไม่เห็นโฟลเดอร์ `.github` (เพราะชื่อขึ้นต้นด้วยจุด จึงถูกซ่อน):
     Windows → เปิด File Explorer → แท็บ View → ติ๊ก **Hidden items**
     Mac → กดปุ่ม `Command + Shift + .` ในหน้าต่าง Finder
7. เลื่อนลงล่าง กด **Commit changes**
8. ตรวจว่าในหน้า repository มีโฟลเดอร์ `.github`, `app` และไฟล์ `build.gradle.kts` อยู่ชั้นบนสุด
9. ถ้าชื่อ branch ไม่ใช่ `main` (เช่นเป็น `master`) ระบบจะไม่เริ่ม build เอง ให้ไปกดสั่งเองตามข้อ 2.3

## 2. ดาวน์โหลดไฟล์ APK

1. ในหน้า repository กดแท็บ **Actions**
2. จะเห็นงานชื่อ **Build APK** กำลังทำงาน (วงกลมสีเหลือง) รอประมาณ 5–10 นาที
3. ถ้าไม่มีงานเริ่มเอง: กด **Build APK** ทางซ้าย → กดปุ่ม **Run workflow** → **Run workflow**
4. เมื่อเสร็จจะขึ้น **เครื่องหมายถูกสีเขียว** ✅ → กดเข้าไปที่งานนั้น
5. เลื่อนลงล่างสุด หัวข้อ **Artifacts** → กด **EmergencyLight-apk** เพื่อดาวน์โหลด
6. ได้ไฟล์ zip มา → แตกไฟล์ → จะได้ **EmergencyLight-debug.apk**
7. ถ้าขึ้น **กากบาทสีแดง** ❌ ให้กดเข้าไปดูข้อความ error แล้วคัดลอกส่งให้ AI แก้

## 3. ติดตั้งบนมือถือ (VIVO X200 Ultra)

1. ส่งไฟล์ `EmergencyLight-debug.apk` เข้ามือถือ (สาย USB, Google Drive, LINE ส่งให้ตัวเอง ฯลฯ)
   หรือเปิดหน้า Actions จากมือถือแล้วดาวน์โหลดตรงๆ ก็ได้
2. แตะไฟล์ APK ในมือถือ
3. ถ้าขึ้นว่า "ไม่อนุญาตให้ติดตั้งแอปจากแหล่งนี้" → แตะ **ตั้งค่า** → เปิด **อนุญาตจากแหล่งนี้** → กดย้อนกลับ
4. กด **ติดตั้ง** (ถ้ามีหน้าเตือนของ Play Protect ให้กด "ติดตั้งต่อไป/Install anyway")
5. จะเห็นไอคอน **Emergency Light** สีแดงบนหน้าจอ

### อัปเดตเวอร์ชันใหม่
build ครั้งถัดไป (ภายในไม่กี่วัน) จะใช้กุญแจเซ็นแอปตัวเดิม จึงติดตั้งทับได้เลยไม่ต้องถอนแอป
(ถ้าไม่ได้ build นานเกิน 7 วัน GitHub อาจลบกุญแจเก่าทิ้ง ครั้งนั้นต้องถอนแอปเก่าก่อนติดตั้ง — ค่าที่ตั้งไว้จะหายไปด้วย)

## 4. ตั้งค่ามือถือ VIVO เพิ่มเติม (แนะนำ)

มือถือ VIVO ชอบปิดแอปที่ทำงานเบื้องหลังเพื่อประหยัดแบต ถ้าไฟฉายหรือ SOS หยุดเองตอนปิดจอ:
- เปิดแอป → ปุ่ม ⚙️ → **Background running** → **Open settings**
- ในหน้าข้อมูลแอป → **แบตเตอรี่** → เลือก **อนุญาตการทำงานเบื้องหลัง / ไม่จำกัด**
